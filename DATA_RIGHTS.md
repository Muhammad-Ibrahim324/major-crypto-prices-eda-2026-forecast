# Data rights and attribution

Author of this analysis package: Muhammad Ibrahim Shahrukh.

The supplied market-data snapshot is reported to come from Yahoo Finance through yfinance. The package preserves that attribution and does not claim ownership of the original prices or provider data.

The [yfinance README](https://github.com/ranaroussi/yfinance) states that the tool is independent of Yahoo, intended for research and education, and that the Yahoo Finance API is intended for personal use. It directs users to Yahoo terms for rights to the actual downloaded data. yfinance's Apache software license does not license that data for redistribution.

Public Kaggle or GitHub data redistribution rights have not been established by this package. Check the current Yahoo and any applicable underlying-provider terms before selecting a dataset license or publishing raw/cleaned data. Do not assume that transformation, attribution, a freely accessible endpoint or a software license grants an open-data license.

No blanket MIT, Apache, CC0 or CC-BY license has been applied to the bundle. Choose a code/documentation license separately if desired, with an explicit exclusion for third-party data. This notice does not make a legal determination about your permissions.
